# Keyboard shortcuts

These are the defaults. To change any of them, go to **Settings › Shortcuts**,
click a shortcut and press the new keys (**Esc** cancels). **Reset** restores one
shortcut and **Reset all** restores every one. In the editor, press **?** to see
the list at any time.

On Windows and Linux, **Ctrl** replaces **⌘**, **Alt** replaces **⌥**, and
**Shift** replaces **⇧**.

## Global

These work even when Reelform isn't in front, but only while the recording
HUD is open or a recording is running, so they don't take keys from other apps
the rest of the time.

| Action | macOS | Windows / Linux |
|---|---|---|
| Start / stop recording | ⇧⌘R | Ctrl+Shift+R |
| Pause / resume recording | ⇧⌘P | Ctrl+Shift+P |
| Record region | ⌥⇧⌘R | Ctrl+Alt+Shift+R |
| Cancel countdown | Esc (during the countdown only) | Esc |

If another app already uses one of these keys, Settings › Shortcuts shows a
warning on that row ("taken by another app"). Choose different keys.

## Timeline

These apply when the timeline has focus.

| Action | macOS | Windows / Linux |
|---|---|---|
| Split at playhead | S | S |
| Trim start to playhead | [ | [ |
| Trim end to playhead | ] | ] |
| Nudge selection −1 / +1 frame | ← / → | ← / → |
| Delete | ⌫ | Delete |
| Ripple delete | ⇧⌫ | Shift+Delete |
| Duplicate | ⌘D | Ctrl+D |
| Select all on track | ⌘A | Ctrl+A |

When the same key is used in more than one area (for example ← steps a frame
in the editor but nudges a selected clip on the timeline), the more specific
area wins while it has focus.

## Mouse and trackpad

- **Drag** a timeline item to move it; **drag an edge** to resize it; **⌥-drag**
  (Alt-drag) to duplicate it.
- **⌘-scroll** (Ctrl-scroll) zooms the timeline around the pointer;
  **⇧-scroll** pans it horizontally.
- **Double-click the ruler** to move the playhead.
- **Drag on an empty track** to marquee-select; **⇧-click** extends the
  selection and **⌘-click** (Ctrl-click) toggles an item.
